Controle Financeiro
Sistema web para controle financeiro pessoal, feito com HTML, CSS e JavaScript.

Funcionalidades:
Registro de entradas e saídas
Cálculo de saldo
Listagem de movimentações

Tecnologias:
HTML, CSS, JavaScript

Como executar:
Baixe o repositório e abra o arquivo index.html no navegador.
